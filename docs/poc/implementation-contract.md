# Implementation contract (TypeScript prototype)

> Historical contract of the TypeScript prototype, kept as a reference for the Rust port.

Import types from shared/model.ts and utilities from shared/graph.ts (relative imports). Only coordinator edits shared files.

Graph.nodes inputs are the source of truth for data bindings. Graph.edges ONLY stores order dependencies. visualEdges() combines both for canvas; never separately store data edges. Multiple named inputs form joins. Binding parameter refers to scenario.parameters or component arguments inside a component. Environment refers to environment variables plus session secrets, including baseUrl.

Request config.url accepts absolute or relative URLs, :argument path parameters, and {{argument}} interpolation. config.headers and config.query map strings with {{argument}} interpolation. node.inputs contains request arguments; inputs.body is optional JSON body. config.sampleResponse/sampleStatus are used ONLY in simulation. Outputs: body/status/headers/duration. Component output bindings refer to internal graph nodes.

Select inputs.value and config.path -> outputs.value. Build all named inputs -> object or array according to config.buildType. Formula inputs.left/right with config.operation -> outputs.value (round uses right as decimal precision). Assert/condition inputs.actual/expected, config.predicate/tolerance; outputs.value preserves actual, outputs.passed boolean. Condition may additionally have config.predicates (input and expected identify named input bindings; path optional) and match all/any. Missing actual is permitted for exists, not silently converted elsewhere.

UI modules use plain props and callbacks; no separate global stores. Coordinator owns Project state and Graph history. GraphCanvas props are finalized in agent handoff. Run API: POST /api/runs with RunRequest returns {id}; GET /api/runs/:id returns RunResult; POST /api/runs/:id/cancel. Optional GET /api/health. Frontend proxies /api to 127.0.0.1:4318. Backend exports runScenario(request, {signal?, onUpdate?}?) Promise<RunResult> from api/runner/index.ts. Logs and returned reports redact secrets. HTTP 4xx/5xx remain assertable outputs.

Use Node's test runner via tsx for focused tests. TypeScript imports without extension work in tsx and Vite. No dependency edits by agents. React Flow (@xyflow/react) is the canvas library. React Router Framework mode and Mantine already exist. Local data persistence belongs to coordinator. Demo fixture APIs belong to coordinator and will be mounted separately; engine must remain domain agnostic.

Block operators: Binding can be `{ kind: "expression", operator, inputs: Record<string, Binding> }`. `shared/operators.ts` is the common operator catalog and strict interpreter. Expressions are eagerly evaluated in argument slots, not standalone test results. All nested reference leaves establish graph dependencies; use `shared/bindings.ts` to visit, rewrite or remove leaves instead of checking only the outer Binding kind. A formula node uses the same operator catalog. Limit: 12 levels and 200 binding nodes per argument. Numeric/boolean operators do not coerce JSON types. JSON field paths remain zero-based; the letter operator is one-based. `and`/`or` evaluate both operands. Persisting, redacting, duplication and component extraction must retain the tree and leaf references.

Variable blocks: `kind: "variable"` resolves `inputs.value` and exposes `outputs.value` without changing its JSON type. The palette uses ordinary reference/parameter/environment bindings, never copied runtime values. Dragging into executable text registers an input alias and inserts `{{alias}}`; `config.templateInputs` declares its port. Input bindings remain the source of graph dependencies. The normal runner template expansion resolves those aliases in URL, query, headers and select/condition paths. `pruneTemplateInputs` drops aliases whose last token was removed. Template port metadata must survive export, duplication and component extraction. Drag payloads contain labels and bindings, never secret values.

Control flow: `trigger` is a manual Start with no inputs/outputs or incoming order edges; at most one per graph. `if` shares assert inputs/predicate/outputs, but false remains passed and chooses ELSE. Only edges sourced at `if` require `branch: "true" | "false"`; other order edges omit it. All operations are awaited. Graphs with Start run reachable paths plus pure value prerequisites; disconnected requests/components stay skipped. Inactive branch order edges propagate skipped, without failure. Alternative order edges merge with OR; data dependencies remain mandatory. A selected single diagnostic step bypasses its own activation gate; nested component graphs still respect theirs. Legacy graphs without Start execute all roots. Duplication and serialization preserve branch metadata. Cleanup retains its independent budget and skips absent resource values.
